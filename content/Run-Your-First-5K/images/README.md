# Image status — first 5K guide

The current 15-step draft has **16 different illustrations**: one cover and one for each step. Each has a 1600×900 and 960×540 WebP variant. Ten images were newly generated for this guide; six were reused from the winter running guide and are recorded under `media.reusedFrom` in `article.json`. The final `02-event` image was cropped to remove unwanted lettering; `07-intervals` uses a slightly lower quality to stay under the 200 KB target. Retain these adjustments if re-exporting.
