# 56juqingba（Howly 复刻站）内容 + 配图生产方案

> 站点定位：英文 how-to 步骤指南站，Howly 版式（3 个 Part / 12 个 Step / Tips / Warnings / Community Q&A / References），配自然光纪实摄影图，变现靠 AdSense 类广告。
> 本方案 = 现有内容诊断 + 选题池 + 单篇生产流水线 + 配图规范 + 30 天排期 + 可直接跑的脚本。仓库里已经交付了 1 篇可发布样板（`content/Keep-Running-Through-Winter/`）。

---

## 1. 现状诊断（抓了你站上的数据得出的结论）

| 维度 | 现状 | 问题 |
|---|---|---|
| 内容形态 | 12 步 / 3 Part，每步一段 + Tip，末尾 Tips、Warnings、5 条 FAQ、4 条参考文献 | 形态没问题，**是这套模板里最值钱的部分，要锁死别改** |
| 内容数量 | 首页/`/new`/`/trending` 共约 12 篇指南 + 1 个 quiz | 类目太空：Sports and Fitness 只有 1 篇，全站撑不起 AdSense 想要的"站点规模 + 主题权威" |
| 类目分布 | 12 类各 1 篇（美妆/跑步/电脑/家务/沟通/汽车/考试/预算/植物/做饭/打包/急救/自然笔记/狗刷牙/油画鉴定/节日传统） | 每类 1 篇 = 每个类目页只有 1 张卡片，**类目页近乎空页，权重分散** |
| 图片 | `/uploads/2026/10/<uuid>-960.webp`，另有 `-1600.webp`，风格统一（35mm、自然光、冷灰调、无人看镜头） | 命名是 UUID，无法批量管理；缺少 alt/图注规范记录 |
| 技术 | 无 `robots.txt` / `sitemap.xml`、无 `wp-json` 可读、curl 被拦但浏览器可访问 | 要么是自研/CMS 带 bot 防护，要么 sitemap 缺失 → **先查收录** |
| 页面细节 | 有作者署名、"subject-matter reviewer"、更新时间、投票、读者数、成功故事 | E-E-A-T 元素齐了，只缺**真实作者身份页** |

**一句话结论**：模板已经对了，缺的是「按主题成簇地批量产内容」+「图片与文字的工业化流水线」。下面全部围绕这两点。

## 2. 目标与节奏（可执行版）

| 阶段 | 周期 | 动作 | 产出 |
|---|---|---|---|
| 补坑 | 第 1 周 | 把已发 12 篇的**同类目第 2、3 篇**补上（每个类目凑到 3 篇） | 类目页从 1 卡变 3 卡 |

## 4. 选题池

见 `content/content-plan.csv`：**25 条**，字段包括 priority / slug / category / 主关键词 / 搜索意图 / 差异角度 / 配图受众 / 目标 URL / 内链对象。

选题优先级打分（每条选题都按这 4 项过一遍）：

| 标准 | 说明 |
|---|---|
| 可步骤化 | 能拆成 9–14 个"动词开头的步骤"，拆不出就写成 explainer，别硬套模板 |
| 有商业价值 | 广告主愿意出价的类目：保险/理财/健康/软件 > 手工/节日 |
| 竞争可切入 | 主关键词前 3 名是 wikiHow/大媒体时，选长尾变体（"winter"、"first 5k"、"in the dark"） |
| YMYL 可控 | 医疗/钱类必须有参考文献 + Warnings，绝不写绝对化结论 |

## 5. 单篇生产流水线（SOP，一篇约 90 分钟）

| # | 步骤 | 工具/输入 | 验收标准 |
|---|---|---|---|
| 1 | 定选题 | `content-plan.csv` 取一行 | 主关键词 + 3 个长尾变体 |
| 2 | 写 `article.json` | `content/_template/article.json` | 12 步、每步 45–110 词、每步带 Tip |
| 3 | 跑体检 | `python3 tools/check_article.py ...` | 0 error |
| 4 | 生成配图 | 见 §6 prompt 模板，1 hero + 每步 1 张 | 13 张 / 篇 |
| 5 | 压缩转码 | `tools/make_images.sh` | 960w/1600w 两档 webp，单张 < 200KB |
| 6 | 导出 | `python3 tools/render_article.py ...` | 得到 `article.md` + `import-payload.json` + 预览页 |
| 7 | 人工审校 | 真人 15 分钟 | 事实、安全提示、语气、图片是否与步骤对得上 |
| 8 | 发布 | CMS 导入 / 粘贴 | 内链、alt、FAQ schema、类目、作者 |

> 第 7 步不能省。AdSense 对"AI 批量生成无审校"的判定很直接，审校记录（谁、哪天）建议留档。

## 6. 配图方案（关键，也是你问的重点）

### 6.1 风格锁（你现在站上的风格，必须固定下来）

```
documentary editorial photography, natural light, 35mm lens,
shallow depth of field, muted cool palette with warm skin tones,
candid, subject not looking at camera, no text, no watermark, no logos
```

统一要素：真人背影/侧脸、环境有生活痕迹（长椅、门廊、厨房台面）、无品牌、无文字、冷灰+一点暖光。

### 6.2 Prompt 公式

```
[动作/状态：谁在做什么] + [环境细节：2–3 个物件] + [光线：时间 + 方向] +
[风格锁] + [构图：16:9、留白方向]
```

实例（本篇 Step 2，可直接复用）：

> A person zipping up a thin running jacket in a hallway by the front door, a folded second layer, gloves and a beanie laid out on a wooden bench beside them, warm indoor light spilling toward a cold bright window — candid documentary editorial photograph, soft natural light, muted palette, 35mm, shallow depth of field, realistic, no text, no watermark, no logos

模板文件：`docs/image-prompt-template.md`

### 6.3 规格

| 项目 | 规格 |
|---|---|
| 比例 | 16:9（hero 与步骤图统一，站上现有图也是宽幅） |
| 尺寸 | 1600×900（hero、类目卡片）+ 960×540（正文内嵌，`srcset` 用） |
| 格式 | WebP，质量 82，`method=6`；单张目标 < 200KB |
| 命名 | `<序号>-<语义>-1600.webp` / `-960.webp`，例：`02-layers-960.webp`（**别用 UUID**） |
| alt | 「主体 + 动作 + 环境」一句，例：`A person zipping up a thin running jacket by the front door, gloves and beanie on a bench` |
| 存放 | 上传到 `/uploads/<yyyy>/<mm>/`，与站上现有路径一致 |
| 每篇数量 | hero 1 + 步骤 12 = 13 张（站上卡片显示 "12 steps · 12 illustrations"，可按需删步骤图到 6 张以内降本） |

### 6.4 批量与成本控制

- **一簇共用视觉语言**：同一簇（跑步簇）的图片用同一套光线/季节/服装色，读者滚动时才有"专题感"。
- **减量策略**：每篇 6 张（hero + 5 步）也能成立，其余步骤用图文卡片；优先给"有动作差异"的步骤配图，重复动作的步骤复用构图。
- **禁止项**：图里出现可读文字、品牌 logo、医疗器械特写（YMYL 风险）、明显错误的解剖/器材。
